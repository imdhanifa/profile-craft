How to use this

  1. Type a GitHub username above and press Generate — it pulls your real profile data and builds a README from it.
  2. Adjust tagline, tech stack, banner, theme, and section toggles. The preview updates instantly, no re-fetch needed.
  3. Copy Markdown copies the whole file to your clipboard. Download README.md saves it locally.

Push it to GitHub

New profile repo (create one on GitHub first, named exactly your username):

mkdir <handle> && cd <handle>
mv ~/Downloads/README.md .
git init
git add README.md
git commit -m "docs: add profile readme"
git branch -M main
git remote add origin https://github.com/<handle>/<handle>.git
git push -u origin main

Already have the repo cloned locally?

cd path/to/<handle>
mv ~/Downloads/README.md .
git add README.md
git commit -m "docs: update profile readme"
git push

Snake / Stats workflow files

If you downloaded either workflow .yml, drop it into this path in the same repo, then commit and push:

.github/workflows/generate-snake.yml
.github/workflows/generate-readme-stats.yml

Then open the Actions tab on the repo to confirm it ran — or trigger it manually with "Run workflow" if it hasn't fired yet.
